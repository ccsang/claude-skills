# Define：图片与视频

## 技法 4：生成图片参与构图

先明确图片承担主体展示、材质、叙事还是情绪。预留构图与文字空间再生成，不随意塞进空白。

> 为【视觉方向】创建用于【位置和用途】的图片，明确【主体、材质、光照、视角、比例、留白】，与【页面底色】协调。让素材承担清晰表达任务，在真实页面检查裁切、边缘、分辨率、层级与文字可读性。

先读取 imagegen 技能。需要时结合着色器或轻量 3D，增强有目的的空间、光影或交互。不靠叠渐变和几何图形掩盖主体缺失，也不声称 CSS 无法产生优秀视觉。

文章涉及内置生图、跨智能体调用、外部 API 三类接入方式。仅使用真实可用且获授权的能力，不假定订阅包含 API 额度。密钥不写入前端、仓库或交付物。缺工具时披露具体缺口，保留可运行占位或静态方案，不伪造结果。

## 技法 5A：物理质感循环微动效

适合晶体、金属、布料等复杂材质局部主体。

1. 指定动作、时长、固定机位与无缝循环，生成纯色底短视频。
2. 透明/折射材质可用页面底色生成，烘焙背景影响再分离背景。更换底色可能暴露局限，不能宣称实时物理折射。
3. 视素材使用色度键控或视频抠图，检查边缘色溢、透明部分破损与光影误删。
4. 用目标浏览器实际支持且已验证的透明视频格式或等效方案集成，检查接缝、比例、解码，提供静态海报回退。

> 把【主体】做成循环微动效：【具体动作】。保持【材质、机位、光照、底色】。用适当的视频生成和背景分离工具完成，在页面检查边缘、循环与底色融合。

## 技法 5B：滚动驱动状态转场

1. 定义状态与内容关系，例如悬浮箱体 → 落地打开 → 物品归位。
2. 生成首状态图，通过图生视频或支持的关键帧功能生成首段过渡。
3. 取前段实际末帧作为下段起点，保持主体、机位、光照、材质连续。逐帧检查，不能只检查首尾。
4. 将滚动区间归一化成进度，再映射为视频时间或序列帧。按真实性能选择实现，不假定所有设备都能丝滑 seek。
5. 测试正反向滚动、片段接点、慢拖和快速跳跃，确认内容与动作同步。

> 为【产品】制作滚动演示，状态为【A/B/C】。先生成首帧，再分段生成过渡；后段以前段实际末帧维持连贯。将转场绑定纵向滚动，运动方向符合阅读直觉。验证逐帧连续性、反向拖动和移动端体验。

实际制作动画或视频前读取 hyperframes 入口，按其工作流选工具；网站交互由网站实现流程集成。外部 API、模型能力、费用和格式按当前官方文档确认，不把文章型号当保证。

## 媒体验收与减法

检查加载失败、低性能设备、静态回退与减少动态效果偏好。装饰视频默认静音，不强占阅读节奏或掩盖操作。删除不改善理解、表达或反馈的素材。所有技法都要评估，但不能因为列在技能里就强行添加。
