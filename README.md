# Claude Skills

This repository contains a collection of skills for Claude Code and serves as a **Claude Plugin Marketplace**.

## Plugin Marketplace
You can install skills directly from this repository using Claude Code.
Registry file: [.claude-plugin/marketplace.json](./.claude-plugin/marketplace.json)

## Skills

###*   [AI Image Generator](skills/ai-image/README.md)- `ai-image`: Generate images using Google Gemini.
*   [YouTube Subtitle Downloader](skills/ydl-js/README.md)- `ydl-js`: Download YouTube subtitles.
*   [YouTube Search](skills/youtube-search/README.md)- `youtube-search`: Search for YouTube videos.
Features:
- Text-to-Image generation
- Streaming support
- Multiple artistic themes
- Google Search integration

## Usage
Navigate to the specific skill directory to learn how to install and use it.
