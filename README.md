# Claude Skills

This repository contains a collection of skills for Claude Code.

## Skills

### [Gemini Image Generator](./skills/gemini-image-generator)
A skill that allows Claude to generate images using Google's Gemini API.
Features:
- Text-to-Image generation
- Streaming support
- Multiple artistic themes
- Google Search integration

## Usage
Navigate to the specific skill directory to learn how to install and use it.
